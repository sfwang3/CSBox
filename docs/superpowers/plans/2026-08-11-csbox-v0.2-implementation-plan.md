# CSBox v0.2 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (\`- [ ]\`) syntax for tracking.

**Goal:** 在不破坏 usable-core 的前提下，把 CSBox 推进为可安装、可审计、可导出 API Evidence 的 v0.2 Alpha。

**Architecture:** API 使用独立的领域模型、TOML parser、ApiTransport port、HTTPX adapter、runner、repository 和 evidence renderer；Textual 只负责 API/Home/Pack 的展示与事件，永不持有 raw secret。Check/Pack/Session 采用增量增强，公共基础仅抽取 display-cell、字体、安全原子写出和 schema versioning。

**Tech Stack:** Python 3.11–3.14、Pydantic 2、HTTPX、PyYAML safe loader、jsonpath-ng、Pillow、Textual、Typer、Rich、uv、pytest/pytest-asyncio/ruff。

## Global Constraints

- Python 最低版本保持 >=3.11，CI 继续覆盖 Ubuntu/Windows 与 Python 3.11/3.14。
- API domain 不得导入 Textual、Typer 或 Rich；HTTPX 只能出现在 transport adapter。
- 所有 persistence、TUI、日志、PNG 文本模型、Markdown、JSON export 只允许使用 redacted 数据。
- TLS verify 默认开启、redirect 默认关闭；不得为了测试默认关闭 TLS 或打印技术 traceback。
- --json 输出以 schema_version: 1 为稳定机器接口；--plain 与 --verbose 只在有意义的命令提供。
- 所有显示宽度使用 display_width/truncate_cells/新的 cell wrapping，不使用 len(text) 做布局。
- 不使用 JavaScript、Python eval、表达式解释器、插件脚本、云端 API 或真实凭据。
- 不删除用户文件、不清空数据库、不 reset/rebase 已有历史、不 force push；临时 smoke 只在 TemporaryDirectory 中工作。
- 每个重要行为遵循 RED → GREEN → REFACTOR；每个任务结尾保留独立逻辑 commit。
