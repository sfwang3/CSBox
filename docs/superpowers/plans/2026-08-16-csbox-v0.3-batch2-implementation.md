# CSBox v0.3 Batch 2 Implementation Plan

> **For agentic workers:** Implement this plan inline with TDD and verify every
> platform claim from the corresponding platform evidence.

**Goal:** Close the Native Windows Lab terminal-state problem family while
preserving the Batch 1 session, recording, Capture transaction, and replay
contracts.

**Architecture:** Keep `TerminalProxy` as the single session ordering owner.
On Windows, one input adapter owns native console observation and exposes key
bytes plus resize notices; it never starts a competing reader. Resize requests
are latest-wins until committed, and a committed backend resize is followed by
one ordered `RESIZE` event. Lab enters a standard alternate screen before
the child starts and restores it after the child output has reached EOF. Child
VT output remains the only source for the emulator; Lab title/status uses a
separate presentation callback and never enters the backend, event
dispatcher, cast, or emulator.

**Tech Stack:** Python 3.11, pytest, pywinpty/ConPTY on Windows, pyte,
`wcwidth`, existing `TerminalProxy`/`TerminalEventDispatcher`/asciicast
pipeline.

## Global Constraints

- Primary Capture is F12; Ctrl-Space is the fallback.
- Do not implement CPR in this batch.
- Do not build a Microsoft Terminal-sized reflow engine.
- Do not add a competing Windows console input reader.
- A failed native resize keeps the last confirmed geometry, publishes a
  title-only warning, and emits no fake `RESIZE` event.
- Native Windows CI and real Windows Terminal manual smoke are distinct gates;
  Linux/fake tests never substitute for either.
- Do not modify Home/onboarding, installation, PyPI, API, Check, Pack,
  workspace, or release/publish workflows.

### Native root-fix addendum

- Normal shutdown is `child EOF → drain/exit status → stop input owner →
  restore surface/state → close ConPTY`; expected EOF and closed-handle races
  are not startup failures.
- On an error path, retry ConPTY close before restoring the surface; if the
  child still cannot be closed, keep the alternate surface owned so a live
  child cannot write into the host screen.
- New recordings do not persist raw `INPUT` bytes. The reader/replay path still
  accepts legacy asciicast `i` events.
